A 4 KB Python chess engine: 0x88 move generation with the kit's env protocol, alpha-beta with quiescence, killer moves, and a material plus piece-square evaluation, searching to a fixed node budget so every trial replays identically.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
